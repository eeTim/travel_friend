# MYKOT 여행친구 파일럿 랜딩페이지

GitHub Pages에 바로 올릴 수 있는 정적 랜딩페이지입니다. 별도의 설치나 빌드가 필요하지 않습니다.

첨부 이미지는 모바일 로딩 속도를 위해 WebP 2종과 JPG 대체 이미지로 최적화되어 있습니다.

## 배포 방법

1. 이 폴더의 `index.html`과 `assets` 폴더를 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고, `main` 브랜치의 `/ (root)`를 저장합니다.

## 이름을 넣어 개인화하기

페이지 주소 뒤에 `?name=이름`을 붙이면 첫 화면이 자동으로 개인화됩니다.

예시:

```text
https://아이디.github.io/저장소/?name=동그래미
```

이름을 넣지 않으면 기본 문구인 “여행친구님의”로 표시됩니다.

## 내용 수정

진행 날짜, 비용 범위, 촬영물 사용 범위가 확정되면 `index.html`의 “파일럿 진행 정보”와 “미리 알려드릴 점” 문구를 실제 조건에 맞게 수정하세요.
